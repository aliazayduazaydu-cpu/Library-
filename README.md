# AM HUN UI Library

مكتبة واجهات لسكربتات Roblox، مبنية على RedzLibrary الأصلية مع شكل مخصص وزر AM HUN.

**الإصدار:** 1.1.0

## المميزات

- 3 ثيمات جاهزة: Darker و Dark و Purple
- حوالي 830 أيقونة من مجموعة Lucide
- تبويبات جانبية قابلة للتعطيل والإخفاء والحذف
- حفظ الإعدادات تلقائياً (الثيم، الحجم، وقيم العناصر)
- زر AM HUN عائم قابل للسحب لفتح وإغلاق الواجهة
- تغيير حجم النافذة وعرض التبويبات بالسحب
- نافذة تأكيد قبل الإغلاق

## الإعدادات العامة

| الإعداد | القيمة الافتراضية |
|---|---|
| حجم الواجهة | 550 × 380 |
| عرض عمود التبويبات | 160 |
| الثيم | Darker |
| ملف الإعدادات | `AM_HUN_config.json` |

## النافذة الرئيسية

- **الشريط العلوي:** العنوان والعنوان الفرعي، وزرا التصغير والإغلاق.
- **التصغير:** يحوّل النافذة إلى شريط صغير بارتفاع 28 بكسل، ويظهر مقبض لإعادة تكبيرها.
- **الإغلاق:** يفتح نافذة تأكيد قبل حذف الواجهة.
- **السحب:** النافذة قابلة للسحب من أي مكان.
- **تغيير الحجم:** مقبض في الزاوية اليمنى السفلية لتكبير النافذة، ومقبض ثانٍ لتغيير عرض عمود التبويبات.
- **زر AM HUN:** زر أسود شفاف 58 × 58 بزوايا دائرية، قابل للسحب، يفتح ويقفل النافذة. مكانه الافتراضي (20, 120).
- **زر تصغير إضافي:** دالة `AddMinimizeButton` تضيف زر تصغير يمكن تخصيص شكله.

## التبويبات

إنشاء تبويب بأيقونة:

```lua
local Tab = Window:MakeTab({ Title = "Main", Icon = "home" })
```

- الأيقونة تقدر تكون اسم من مكتبة الأيقونات (مثل `home` أو `lucide-home`)، أو رابط `rbxassetid://` مباشرة.
- كل تبويب فيه: `Disable` و `Enable` و `Visible(bool)` و `Destroy`.

## العناصر داخل التبويب

### AddSection
عنوان قسم عريض لتقسيم الصفحة.
- الدوال: `Set(نص)`، `Visible`، `Destroy`.

### AddParagraph
عنوان ووصف بدون زر.
- الدوال: `SetTitle`، `SetDesc`، `Set(عنوان, وصف)`، `Visible`، `Destroy`.

### AddButton
زر فيه اسم ووصف وكول باك، ومع أيقونة صغيرة على اليمين.

```lua
Tab:AddButton({
    Name = "Click Me",
    Desc = "Shows a message",
    Callback = function()
        print("clicked")
    end
})
```

- الدوال: `Callback(...)` لتشغيله يدوياً، `Set(نص)`، `Visible`، `Destroy`.

### AddToggle
مفتاح تشغيل وإيقاف. الكول باك يرجع `true` أو `false`.
- الترتيب: الاسم، القيمة الافتراضية، الكول باك، والـ Flag.
- الدوال: `Set`، `Callback`، `Visible`، `Destroy`.

### AddDropdown
قائمة منسدلة بخيار واحد أو **اختيار متعدد** (`MultiSelect = true`).
- الدوال: `Add(خيار)`، `Remove(خيار)`، `Select(خيار)`، `Set(قيمة, مسح)`، `Callback`.

### AddSlider
شريط تمرير يعرض القيمة الحالية.
- الترتيب: الاسم، أقل قيمة، أعلى قيمة، مقدار الزيادة، القيمة الافتراضية، الكول باك، والـ Flag.
- الدوال: `Set`، `Callback`، `Visible`، `Destroy`.

### AddTextBox
مربع نص يشتغل لما المستخدم يخلّص الكتابة أو يضغط Enter.
- الخيارات: القيمة الافتراضية، مسح النص عند التركيز، النص التوضيحي (Placeholder)، والكول باك.
- دالة `OnChanging` تقدر تعدّل النص قبل تنفيذ الكول باك.

### AddDiscordInvite
بطاقة فيها شعار وعنوان ووصف وزر **Join** ينسخ رابط الدعوة للحافظة، ويتغير النص إلى "Copied to Clipboard" لمدة 5 ثواني.

## الدوال العامة

| الدالة | الوظيفة |
|---|---|
| `AMHUN:MakeWindow(...)` | ينشئ النافذة |
| `AMHUN:SetTheme(اسم)` | يغيّر الثيم ويحفظه |
| `AMHUN:SetScale(رقم)` | يغيّر حجم الواجهة حسب الشاشة |
| `AMHUN:GetIcon(اسم)` | يحوّل اسم الأيقونة لرابطها |
| `Window:Dialog(...)` | يفتح نافذة حوار فيها أزرار مخصصة |
| `Window:Set(...)` | يغيّر عنوان النافذة والعنوان الفرعي |

## المشاكل المعروفة

- في `SetTheme` مكتوب `Comnection` بدل `Connection`، فتغيير الثيم ممكن يطلع خطأ.
- دالة `table.foreach` محذوفة من Luau الحديث، ويفضل تبديلها بـ `pairs`.
- في `AddDiscordInvite` مكتوب `TextWrapped = "Y"` والصح `true`.

## الاستخدام

```lua
local AMHUN = loadstring(game:HttpGet("RAW_URL_HERE"))()

local Window = AMHUN:MakeWindow({
    Name = "AM HUN",
    SubTitle = "by علاوي",
    SaveFolder = "AM_HUN_Config.json"
})

local Main = Window:MakeTab({ Title = "Main", Icon = "home" })
Main:AddButton({ Name = "Hello", Callback = function() print("Hi") end })
```

> استبدل `RAW_URL_HERE` برابط الملف الخام (Raw) بعد رفعه على GitHub.
